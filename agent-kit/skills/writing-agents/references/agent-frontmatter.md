# Agent Frontmatter Field Reference

| Field             | Format                                                                        | Notes                                                                                                                                                                                                                                                            |
| ----------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`            | lowercase, numbers, hyphens                                                   | Unique. No `:` (reserved for plugin scope) and no leading `-`; Claude Code skips files that break either rule                                                                                                                                                    |
| `description`     | string                                                                        | When the parent should delegate. Loaded into every parent request; the body loads only when the agent runs. Project cap 1024 chars (Claude Code warns when all custom descriptions together exceed 15,000 tokens). See the Description Field section in SKILL.md |
| `model`           | `opus` / `sonnet` / `haiku` / `fable` / full model ID / `inherit`             | Optional. A `model` passed on the Agent call overrides it. Omitted: `CLAUDE_CODE_SUBAGENT_MODEL` if set, else the main session's model. See `project-patterns.md` Section 2 |
| `effort`          | `low` / `medium` / `high` / `xhigh` / `max`                                   | Optional. Overrides the session effort for this agent; omitted inherits it. Available levels depend on the model. See `project-patterns.md` Section 2                                                                                                            |
| `tools`           | comma-separated string or list                                                | Optional. Omit for all tools. Prefer least privilege. Accepts `mcp__<server>__*`                                                                                                                                                                                 |
| `disallowedTools` | same as `tools`                                                               | Optional. Removed before `tools` is resolved; `Bash(git push *)` removes the whole Bash tool                                                                                                                                                                     |
| `permissionMode`  | `default` (alias `manual`) / `acceptEdits` / `auto` / `dontAsk` / `bypassPermissions` / `plan` | Optional. Ignored when the parent runs in `bypassPermissions`, `acceptEdits`, or auto mode. A declared `bypassPermissions` takes effect only when the parent already bypasses |
| `maxTurns`        | integer                                                                       | Optional. Limit agentic turns; output is returned marked partial                                                                                                                                                                                                 |
| `skills`          | list of skill names                                                           | Optional. Preloads each skill's full content at startup; unlisted skills stay invocable                                                                                                                                                                          |
| `mcpServers`      | list of server names or inline definitions                                    | Optional. MCP servers available                                                                                                                                                                                                                                  |
| `hooks`           | hook config object                                                            | Optional. Agent-specific hooks; `Stop` runs as `SubagentStop`                                                                                                                                                                                                    |
| `memory`          | `user` / `project` / `local`                                                  | Optional. Enables a persistent agent memory directory                                                                                                                                                                                     |
| `background`      | boolean                                                                       | Optional. Run in background                                                                                                                                                                                                                                      |
| `isolation`       | `worktree`                                                                    | Optional. Run in isolated worktree.                                                                                                                                                                                   |
| `color`           | `red` / `blue` / `green` / `yellow` / `purple` / `orange` / `pink` / `cyan`   | Optional. UI color                                                                                                                                                                                                                                               |
| `initialPrompt`   | string                                                                        | Optional. First user turn when the agent runs as the main session (`--agent`)                                                                                                                                                                                    |
| `omitClaudeMd`    | boolean                                                                       | Optional. `true` starts the agent without the user, project, and local CLAUDE.md files, project rules included. Only for agents that take everything from the delegation prompt; agents that rely on inherited rules must not set it |
| `experimental`    | map                                                                           | Optional. `cacheTtl: 5m` or `1h` sets this agent's prompt-cache lifetime                                                                                                                                                                                         |
| `autoCompactWindow` | number                                                                      | Optional. Accepted by the schema; semantics undocumented here                                                                                                                                                                                                    |

Field names are camelCase and must match exactly: Claude Code silently ignores a field it doesn't recognize.

## Overriding built-in agents

- A project agent file whose `name` matches a built-in (`Explore`, `Plan`) replaces it entirely: prompt, model, tools and description. To change only the model, copy the built-in's prompt and settings and change `model`. `.claude/agents/Explore.md` is the example.
- Built-in Explore and Plan use `model: inherit` and `omitClaudeMd: true`; on the Anthropic API, Explore's inherit is capped at opus.
- `CLAUDE_CODE_SUBAGENT_MODEL` doesn't change Explore. `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` does, but it forces every subagent, including any pinned to a specific model.
- Built-in prompts live in the Claude Code binary (`readlink -f "$(which claude)"`), about 250 MB: don't `cat` or `strings` it. Search its bytes with `python3 -I`; the second hit of the prompt's first sentence holds the JS template with its `${...}` placeholders, and `agentType:"<Name>"` gives the definition.
- Agent files load at session start; a file added mid-session doesn't load. Test a new or changed agent in a new session.

## Plugin agents

- A plugin's agent is addressed as `<plugin>:<name>`; that is the `subagent_type` callers pass and the `agent_type` hooks receive.
- Plugin agents silently ignore the `hooks`, `mcpServers`, `permissionMode` and `initialPrompt` frontmatter fields. Put behaviour in the plugin's own `hooks/hooks.json` instead, keyed on `agent_type`.
- Unknown frontmatter keys are ignored without error, so a misspelled field fails silently.
- Frontmatter hooks of any agent are cached for the session: editing them needs a new session.
- A hook can't reliably find an agent's definition file from `agent_type`; keep per-agent settings in the plugin's `config/`.
- The plugin's `bin/` is on the Bash tool's PATH in the main session and in subagents, after the user's own PATH. Call its scripts by bare name. `${CLAUDE_PLUGIN_ROOT}` is substituted only in the plugin's own agent and skill bodies, not in a project's.
